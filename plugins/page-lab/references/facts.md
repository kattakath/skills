# page-lab — measured facts

**A row marked UNVERIFIED is not promoted by editing this table — it is promoted by re-running its
recipe and dating the result.** Editing the date, the wording, or the `Measured` column without
re-running the recipe is a fabrication, not an update. Same discipline as `patterns.md`'s
*Flagged — NOT verified* table and `probes.md`'s *Honest caveats*: epistemic hygiene, **not a backlog**.

## What this file is

Every fact in this plugin that an upstream bump can falsify lives here **once**, with an ID, a date
and a recipe. Everywhere else states the fact in at most one clause and cites `[F-ID]`.

- Citing: write `[F-CDP-29TOOLS]` inline. `checks.<system>.page-lab` fails the build on a `[F-…]`
  citation with no row here.
- Restating: do not. A second prose copy of a volatile fact is the drift this file exists to kill.
- Promoting an UNVERIFIED row: run its recipe, paste the observed result into the `Fact` cell,
  move the row into the measured table, and date it **the day you ran it**.
- `Cited by` is maintained by hand and is a convenience, not an authority — the CI grep is.
- Recipes are written for the **rendered** table: a `\|` in the raw source is a literal `|` in the
  command. Copy from the rendered view, or unescape — an escaped pipe pasted into a shell is a
  literal character, not a pipeline.

## Two harnesses the recipes reuse

Run both under Node 22 (`nix shell nixpkgs#nodejs_22 -c bash`) — the fleet's default Node has no
global `WebSocket` [F-NODE-NO-WS]. Paths are relative to `plugins/page-lab/`.

```bash
# H-MCP — dump a stdio MCP server's tool names.  Usage: h_mcp npx -y <pkg>@<ver> [flags...]
h_mcp() {
  printf '%s\n' \
    '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2024-11-05","capabilities":{},"clientInfo":{"name":"page-lab-facts","version":"0"}}}' \
    '{"jsonrpc":"2.0","method":"notifications/initialized"}' \
    '{"jsonrpc":"2.0","id":2,"method":"tools/list"}' \
    | "$@" 2>/dev/null | jq -c 'select(.id==2) | .result.tools | map(.name)'
}

# H-CDP — send ONE CDP method to the first page target of a debug browser on :9222.
# Usage: h_cdp Overlay.setInspectMode '{"mode":"none"}'
h_cdp() {
  params="${2:-}"; [ -n "$params" ] || params='{}'
  node --input-type=module -e '
    import { browserSocket, connect, pageTargets, attach } from "./scripts/lib/cdp.mjs";
    const c = await connect(await browserSocket("http://127.0.0.1:9222"));
    const t = (await pageTargets(c))[0];
    const s = await attach(c, t.targetId);
    await c.send("DOM.enable", {}, s);
    await c.send("DOM.getDocument", { depth: 0 }, s);
    console.log(JSON.stringify(await c.send(process.argv[1], JSON.parse(process.argv[2]), s)));
    c.close();
  ' "$1" "$params"
}
```
